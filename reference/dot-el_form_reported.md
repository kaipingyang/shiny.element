# The fields given `report = TRUE`, as inputs and the paths they report

The fields given `report = TRUE`, as inputs and the paths they report

## Usage

``` r
.el_form_reported(fields, ns_id)
```

## Arguments

- fields:

  The form's fields, flattened.

- ns_id:

  The form's id.

## Value

A named character vector: `model.<prop>` named `<id>_<prop>`.
