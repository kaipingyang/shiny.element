# Build one of the Element UI container parts

Build one of the Element UI container parts

## Usage

``` r
.el_container_part(
  class,
  children,
  size = NULL,
  size_prop = NULL,
  style = NULL,
  extra_class = NULL
)
```

## Arguments

- class:

  The Element UI class name, e.g. `"el-header"`.

- children:

  Child elements.

- size:

  Inline `height` or `width` value, or `NULL`.

- size_prop:

  Which CSS property `size` sets.

- style:

  Extra inline style.

- extra_class:

  Extra CSS classes.

## Value

A Shiny UI element.
