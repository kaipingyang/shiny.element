# A locale's file alone, English's included

[`el_locale_dependency()`](https://kaipingyang.github.io/shiny.element/reference/el_locale_dependency.md)
also makes the locale the page's; a config provider needs only the
object the file defines, `ElementPlusLocaleZhCn`.

## Usage

``` r
.el_locale_file(code)
```

## Arguments

- code:

  A locale code, `"zh-cn"`.

## Value

An htmlDependency.
