# Send fields to a component: the shinyVueUpdate message

Send fields to a component: the shinyVueUpdate message

## Usage

``` r
.vue_send_update(session, msg)
```

## Arguments

- session:

  A Shiny session.

- msg:

  `list(id =, <field> = <value>, ...)`; dot-keys are the bridge's.

## Value

`NULL`, invisibly.
