# An icon inside a component's template

Where Vue compiles the markup – a menu, a dropdown, a slot – an icon is
Element Plus's own `<el-icon>` holding the icon component. A tag is
passed through.

## Usage

``` r
.el_vue_icon(x)
```

## Arguments

- x:

  An icon's name (any form
  [`el_icon()`](https://kaipingyang.github.io/shiny.element/reference/el_icon.md)
  takes), or a tag.

## Value

Markup.
