# Rewrite field names inside a JS function body

Rewrite field names inside a JS function body

## Usage

``` r
.el_rewrite_js(js, rename)
```

## Arguments

- js:

  An [`htmlwidgets::JS()`](https://rdrr.io/pkg/htmlwidgets/man/JS.html)
  string.

- rename:

  Named character vector, old name to new.

## Value

The function, rewritten.
