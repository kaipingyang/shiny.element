# The Element colours a theme changes

The Element colours a theme changes

## Usage

``` r
.el_theme_colors(colors)
```

## Arguments

- colors:

  A
  [`bslib::bs_theme()`](https://rstudio.github.io/bslib/reference/bs_theme.html),
  or a named list or vector of `primary`, `success`, `warning`,
  `danger`.

## Value

A named character vector of the colours that differ from Element's,
possibly empty.
