# Where the JavaScript is in a list

The paths, dot-separated, of every
[`JS()`](https://kaipingyang.github.io/shiny.element/reference/JS.md)
value, for the page to evaluate. A dot in a name is escaped.

## Usage

``` r
.el_js_paths(x)
```

## Arguments

- x:

  A list.

## Value

A character vector of paths.
