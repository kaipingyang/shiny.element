# Bind the per-item props a menu item or submenu was given

Bind the per-item props a menu item or submenu was given

## Usage

``` r
.el_menu_item_props(item, fields)
```

## Arguments

- item:

  One item description.

- fields:

  The snake_case fields to look for.

## Value

A list of `:kebab-case` bindings, one per field present.
