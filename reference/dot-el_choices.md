# The values Element accepts for its enumerated props

Generated by `tools/ep-choices.py` from Element Plus 2.14.7's API
tables: every argument that is an enumerated prop upstream, with no
free-form alternative (an `effect` that also takes any string is not
checked). A prop that also takes a number – an avatar's `size` – is
checked only when given a string.

## Usage

``` r
.el_choices
```
