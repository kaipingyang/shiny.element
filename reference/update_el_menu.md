# Update an Element UI Menu

Update an Element UI Menu

## Usage

``` r
update_el_menu(session, id, active = NULL, collapse = NULL)
```

## Arguments

- session:

  Shiny session object.

- id:

  Menu ID (un-namespaced).

- active:

  Index of the item to select.

- collapse:

  New collapsed state.

## Value

Called for its side effect; returns `NULL` invisibly.
