# Element Plus Main

Element Plus Main

## Usage

``` r
el_main(..., style = NULL, class = NULL)
```

## Arguments

- ...:

  Content.

- style:

  Extra inline style.

- class:

  Extra CSS classes.

## Value

A Shiny UI element.
