# Element's dependency, with its stylesheet built for a theme

Element's dependency, with its stylesheet built for a theme

## Usage

``` r
.el_themed_dependency(vars)
```

## Arguments

- vars:

  Output of
  [`.el_element_vars()`](https://kaipingyang.github.io/shiny.element/reference/dot-el_element_vars.md).

## Value

An htmlDependency, or `NULL` when nothing changes.
