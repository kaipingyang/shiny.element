# Normalise one or several validation rules into a list of rules

Normalise one or several validation rules into a list of rules

## Usage

``` r
.el_normalize_rules(rules)
```

## Arguments

- rules:

  A single
  [`el_rule()`](https://kaipingyang.github.io/shiny.element/reference/el_rule.md),
  a list of them, or `NULL`.

## Value

An unnamed list of rules, or `NULL`.
