# The `use` of a component as the bridge reads it

The `use` of a component as the bridge reads it

## Usage

``` r
.vue_use(use)
```

## Arguments

- use:

  `c("PluginA", "PluginB")`, or a list naming a plugin with its options:
  `list(PluginA = list(size = "small"), "PluginB")`.

## Value

A list of names and `list(name =, options =)`.
