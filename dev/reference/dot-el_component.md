# A component's specification

A component's specification

## Usage

``` r
.el_component(fn, args, class)
```

## Arguments

- fn:

  The function that draws it, by name: `".el_table_tags"`.

- args:

  Its arguments.

- class:

  The component's class, `"el_table"`.

## Value

An object of class `class` and `el_component`.
