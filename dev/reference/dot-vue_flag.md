# A value as a field holding `true` or `false`

A value as a field holding `true` or `false`

## Usage

``` r
.vue_flag(x)
```

## Arguments

- x:

  A value, or a
  [`vue_bind()`](https://kaipingyang.github.io/shiny.element/dev/reference/vue_bind.md),
  which is kept.

## Value

`TRUE`, `FALSE` or the binding.
