# Element's element-loading-\* attributes

Element's element-loading-\* attributes

## Usage

``` r
.el_loading_attrs(options)
```

## Arguments

- options:

  A list named as
  [`el_loading()`](https://kaipingyang.github.io/shiny.element/dev/reference/el_loading.md)'s
  arguments, or `NULL`.

## Value

A named list of attributes.
