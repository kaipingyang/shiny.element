# One tab's header item

One tab's header item

## Usage

``` r
.el_tab_item(ns_id, t, active, closable, pos_class)
```

## Arguments

- ns_id:

  The tabs' namespaced id.

- t:

  The tab description.

- active, closable:

  Whether it is selected, and whether it can be closed.

- pos_class:

  `is-top`, `is-left`, ...

## Value

A tag.
